# Saturn Dashboard v3.7.5

### Novidades, Correções e Melhorias na Versão 3.7.5

### 💻 Interface do Terminal Web Simplificada e Focada
- **Remoção do Terminal Interno Direto:** Descontinuado o atalho de acesso direto ao shell interno do sistema, unificando a tela de autenticação do terminal.
- **Foco em Conexão SSH Padrão:** O modal de conexão agora apresenta diretamente o formulário seguro de SSH (usuário, senha, porta e configurações avançadas de host), garantindo controle de credenciais e ergonomia visual limpa.
