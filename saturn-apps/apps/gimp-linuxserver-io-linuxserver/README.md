# Gimp (LinuxServer.io)

A free and open-source raster graphics editor used for image manipulation (retouching) and image editing, free-form drawing, transcoding between different image file formats, and more specialized tasks. It is extensible by means of plugins, and scriptable.

- **Categoria:** Home
- **Desenvolvedor:** LinuxServer.io
- **Origem:** linuxserver
