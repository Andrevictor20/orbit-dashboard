# Babybuddy (LinuxServer.io)

A buddy for babies. Helps caregivers track sleep, feedings, diaper changes, tummy time and more to learn about and predict baby's needs without (as much) guess work.

- **Categoria:** Home
- **Desenvolvedor:** LinuxServer.io
- **Origem:** linuxserver

## Como usar no Saturn
Instale este aplicativo diretamente através do Saturn Dashboard.
