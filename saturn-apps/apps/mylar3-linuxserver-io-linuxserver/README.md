# Mylar3 (LinuxServer.io)

An automated Comic Book downloader (cbr/cbz) for use with NZB and torrents written in python. It supports SABnzbd, NZBGET, and many torrent clients in addition to DDL.

- **Categoria:** Home
- **Desenvolvedor:** LinuxServer.io
- **Origem:** linuxserver

## Como usar no Saturn
Instale este aplicativo diretamente através do Saturn Dashboard.
