# Librewolf (LinuxServer.io)

A custom and independent version of Firefox, with the primary goals of privacy, security and user freedom. LibreWolf also aims to remove all the telemetry, data collection and annoyances, as well as disabling anti-freedom features like DRM.

- **Categoria:** Home
- **Desenvolvedor:** LinuxServer.io
- **Origem:** linuxserver

## Como usar no Saturn
Instale este aplicativo diretamente através do Saturn Dashboard.
