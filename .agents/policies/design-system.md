# Design System Policy

- Reutilize tokens semânticos em vez de hardcoding (evite `19px` ou `#ff0000`).
- Novos componentes devem ser desenhados visando reutilização e devem ser inseridos no component registry.
- Combata ativamente o Design System Drift (criações desnecessárias que conflitam com os padrões visuais existentes).
