# Frontend Performance

Verifique e atue sobre:
- Bundle size, code splitting, lazy loading.
- Otimização de imagens, fontes e re-renders desnecessários.
- Métricas Core Web Vitals (LCP, INP, CLS) quando aplicável.
Não aplique memoização indiscriminada sem evidência de gargalo de performance.
