# Security Testing

Testar proativamente abusos, sempre em ambiente controlado (nunca produção):
- Auth bypass, authorization bypass, mass assignment.
- Injection, XSS, SSRF, path traversal.
- DAST em staging quando aplicável.
Essa skill interage com a suíte de integração e o Threat Model.
