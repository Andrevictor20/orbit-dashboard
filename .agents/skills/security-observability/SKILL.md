# Security Observability

Monitoramento de infraestrutura focado em segurança:
- Alarmes e logs para failed logins, abuse em password reset, falhas de autorização.
- Monitorar spikes incomuns de erro ou violações de rate-limit.
- **Nunca logue senhas, acess tokens, session cookies ou APIs secrets em logs**.
