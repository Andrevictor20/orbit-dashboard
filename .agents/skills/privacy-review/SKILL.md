# Privacy Review

Quando a tarefa processa dados pessoais:
- Princípio do menor privilégio / minimização de dados.
- Qual a finalidade e a retenção do dado processado?
- Avaliar riscos de exposição acidental de dados sensíveis.
- Sinalizar riscos técnicos e recomendar revisão de produto/jurídica se as proteções de consentimento não estiverem claras.
