# Design Tokens

Sempre utilize tokens semânticos (`color.background`, `color.primary`) em vez de dependências diretas de hexadecimais espalhados.
- Cores
- Tipografia
- Espaçamento
- Radius, Shadow, Border
- Z-index, Motion, Breakpoint

Evite hardcoding na UI (ex: `19px` ao invés do token correspondente no sistema).
