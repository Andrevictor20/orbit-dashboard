# Visual Regression Guardian

Garante que mudanças de código não quebrem a fidelidade visual de componentes em outras partes.
- Compare baseline com alterações novas.
- Revise responsividade e os vários estados (hover, focus, disabled).
- Verifique o suporte a dark mode via semantic tokens.
Nunca use apenas screenshot; integre visual QA com testes comportamentais.
